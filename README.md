## MOC 종류 ##
*MOC 구매전 핀개수와 모듈, 기능을 살펴보고 구매해야함*
- 아두이노
  - 아두이노 나노 : 작은데 비쌈
  - 아두이노 우노 : 쉽고 일반적임
- esp32 : wi-fi, blu 됨. IoT, 웨어러블에 많이 씀  |  esp32는 제조사에 따라서도 펌웨어가 바뀌므로 주
  + esp32 : 일반적
  + esp32-c3 : 작은데, 기능과 성능이 떨어짐
  + esp32-s3 : 성능이 가장 좋다고 알려짐
  + 확장보드 : esp32에 확장 보드를 끼워서 버튼등의 기능이나 핀 개수를 늘릴 수도 있
+ 라즈베리파이 : os가 있음. os로 키오스크 등을 실행시키기 좋음
+ 젯슨(jetson) : 고성능 gpu라서 인공지능 실행시키기 좋음
