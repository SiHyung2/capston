## Thonny에서 제공하는 라이브러리 설치법 ##

1. Thonny 실행
2. "도구" → "패키지관리" →
3. 검색창에 "라이브러리 이름" 입력 후 선택
4. 설치 버튼 클릭
5. 설치 완료 후, 쉘에서 아래 명령어 실행하여 설치 확인

```
// 라이브러리 설치 확인 예시
import 라이브러리명 as 라이브러리 별칭
print(라이브러리 별칭.__version__)  # 라이브러리의 버전 확인
		# 만약, AttributeError: type object '라이브러리명' has no attribute '__version__'
		# 이 출력된다면, 라이브러리를 사용해보면서 테스트할 수 밖에 없음 
```


6. (대체방법) 터미널에서 직접 설치할 경우
```
$ pip install mediapipe
```



## 외부 라이브러리 설치법 ##

1. 새파일 만들기
2. 해당파일의 코드를 복사한다
3. 저장하기 -> micropyhon에 저장하기
4. 이름과 확장명을 맞춰준다
5. 파일위치는 최상단 폴더!
6. 만약, lib 폴더에 설치한다면 "import lib.라이브러리"와 같이 전처리해야함
